Code and results on GitHub

Did they build what the drawings say?

FerroSight reads a steel building's structural drawings, watches a walkthrough video of the site, and points to every member that is missing, moved, or the wrong size, with the evidence.

 

Drag to orbit. Click a glowing member to see the evidence.
Test buildings are synthetic, rendered in Blender, so every answer can be checked; the answer key is shown under each finding. The vision-language model's opinion is shown for comparison only.
